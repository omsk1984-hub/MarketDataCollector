# Журнал прогресса воркфлоу `<название воркфлоу>`

Единственный источник истины о состоянии конвейера. Обновляется после завершения каждого пункта.

## Статусы

- `⏳` — в работе
- `✅` — завершено (реализовано и подтверждено по DoD)
- `⛔` — отклонено / требуется доработка
- `⏸️` — приостановлено / ожидает

## Журнал

| Пункт | Статус | Результат | Комментарий |
|-------|--------|-----------|-------------|
| 1 | ⏸️ | — | Ожидает запуска |
| 2 | ⏸️ | — | Ожидает запуска |
| 3 | ⏸️ | — | Ожидает запуска |

---

## Правила ведения

1. Перед началом каждого пункта агент помечает строку статусом `⏳`.
2. По завершении пункта агент заполняет `Результат`, выставляет `✅` и (при необходимости) комментарий.
3. Переход к следующему пункту возможен только при `✅` на предыдущем.
4. Если пункт признан уже выполненным на шаге проверки — статус `✅` с комментарием «уже выполнено».
5. Замечания/причины отклонения фиксируются в колонке `Комментарий`.
