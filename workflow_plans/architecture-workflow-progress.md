# Журнал прогресса воркфлоу `architecture-improvements`

Единственный источник истины о состоянии конвейера. Обновляется каждым агентом после завершения своего шага.

## Статусы

- `⏳` — в работе
- `✅` — завершено (одобрено ревью)
- `⛔` — отклонено ревью / требуется доработка
- `⏸️` — приостановлено / ожидает

## Правила ведения

1. Перед началом каждого шага агент помечает строку своего пункта/роли статусом `⏳`.
2. По завершении шага агент заполняет `Результат`, выставляет `Ревью` (если применимо) и ставит `✅` или `⛔`.
3. Переход к следующему шагу/пункту возможен только при `✅` на предыдущем.
4. Замечания ревьюера фиксируются в колонке `Комментарий`.
