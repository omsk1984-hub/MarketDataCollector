## 10. Выводы и Рекомендации

### ✅ Что работает хорошо:
1. **Стабильная генерация тиков:** FakeTickServer стабильно генерирует ~20K тиков/сек на символ.
2. **Эффективная дедупликация:** 2.5–3.0% дублей отсеиваются.
3. **Batch write:** Средняя 150–200 мс для 2,000 тиков — приемлемо.
4. **GC:** Суммарная пауза 0.43% — не критично.

### ⚠️ Проблемы:
1. **Channel Backlog 3,879** — процессор не успевает. Причина: конкуренция за БД.
2. **Outliers batch write до 1.57 сек** — вызывает рост очередей.
3. **29,869 таймеров** — аномально. Требуется оптимизация.
4. **41 исключение** — нужно расследовать.
5. **Gen2 GC 4 раза за 66 сек** — часто для LOH.

### 📋 Рекомендации:
1. **Увеличить batch size** с 2,000 до 5,000 — снизит количество запросов к БД.
2. **Добавить retry/backoff** для batch write при таймаутах.
3. **Оптимизировать таймеры** — возможно,Many таймеров создаются повторно.
4. **Расследовать исключения** — найти источник 41 исключения.
5. **Мониторинг Gen2 GC** — если продолжает расти, рассмотреть Large Object Heap compaction.
