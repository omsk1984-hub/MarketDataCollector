# План: сводный отчёт о покрытии кода в консоль (без HTML)

## Цель
Доработать запуск тестов так, чтобы в консоль выводился короткий сводный отчёт
о покрытии кода тестами: общий % строк и % веток, а также разбивка по ключевым
сборкам/классам. Никакого HTML и генераторов отчётов.

## Текущее состояние
- `coverlet.collector` v6.0.0 уже подключён в тестовом проекте
  (`tests/MarketDataCollector.Tests/MarketDataCollector.Tests.csproj`).
- Текущий `run_test.ps1` просто запускает `dotnet test` без сбора покрытия.

## Подход
1. Запуск тестов с коллектором:
   `dotnet test ... --collect:"XPlat Code Coverage" --results-directory TestResults`
   → результат: `TestResults/<guid>/coverage.cobertura.xml`.
2. Парсинг `coverage.cobertura.xml` средствами PowerShell (XML — без внешних зависимостей):
   - атрибуты корня: `line-rate`, `branch-rate` → общий % строк/веток;
   - атрибуты `<class>`: `filename`, `line-rate` → разбивка по классам;
   - исключить из разбивки классы тестового проекта (путь содержит `tests/`
     или имя сборки `MarketDataCollector.Tests`).
3. Вывод сводки в консоль:
   - общий % покрытия строк и веток;
   - топ-N классов с наименьшим покрытием (для точек роста);
   - итоговый вердикт (порог в переменной, по умолчанию 0 — без падения).

## Изменяемые файлы
- `run_test.ps1` — основной скрипт (сохранить существующий запуск без покрытия
  по-прежнему возможным или всегда включать покрытие — по предпочтению).
- Тестовый `.csproj` трогать НЕ нужно (коллектор уже есть).
- Артефакты покрытия складывать в `TestResults/`, добавить в `.gitignore`.

## Примечания
- Кодировка: вывод кириллицы в консоль выполнять через обёртку
  `chcp 65001 >nul & cmd /c ...` согласно правилам проекта.
- Новых NuGet-пакетов и глобальных инструментов не требуется.
