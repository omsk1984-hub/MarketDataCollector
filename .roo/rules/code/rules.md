# Правила кода

- `async/await` до самого низкого уровня
- `ConfigureAwait(false)` только в библиотеках
- Null-check через `ArgumentNullException.ThrowIfNull()`
- Логирование через `ILogger<T>`
- Тесты покрывают happy path + edge cases
- Использовать `dotnet format` перед коммитом

## Выполнение команд и работа с кодом

- Всегда явно спрашивай пользователя перед выполнением нагрузочного тестирования и запуском FakeTickServer.exe.
- Все консольные команды выполняй как `chcp 65001 >nul & cmd /c <команда>` (например: `chcp 65001 >nul & cmd /c echo Привет`) — обёртка `cmd /c` стабильно даёт правильную кодировку кириллицы.
- Не генерируй Program.cs целиком, если об этом явно не просили.
- При добавлении NuGet-пакета показывай команду `dotnet add package`.
- Всегда указывай `using` явно, не полагайся на implicit usings.
